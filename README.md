# 📊 Customer Insight Recommendation System

An interactive Business Intelligence dashboard built to analyze customer behavior, sales performance, and generate data-driven business recommendations.

This project helps businesses understand customers, identify sales opportunities, improve retention strategies, and make smarter decisions using data analytics.

---

## 🚀 Project Overview

The Customer Insight Recommendation System analyzes e-commerce sales data and converts raw information into meaningful business insights.

The system performs:

- Customer Analysis
- Sales Performance Tracking
- Product Performance Analysis
- Customer Segmentation
- Business Recommendation Generation

---

## 🎯 Objectives

✔ Analyze customer and sales data  
✔ Identify high-value customers  
✔ Understand buying patterns  
✔ Track revenue trends  
✔ Generate actionable business strategies  
✔ Build an interactive analytics dashboard  

---

## ✨ Features

### 📌 Dynamic KPI Dashboard

- Total Customers
- Total Sales
- Total Orders
- Average Order Value

---

### 👥 Customer Insights

- Top Revenue Customers
- Repeat vs New Customer Analysis
- Customer Purchase Behaviour

---

### 🎯 Customer Segmentation

Customers are classified into:

- High Value Customers
- Medium Value Customers
- Low Value Customers

based on their purchasing behavior.

---

### 📈 Sales Analytics

Includes:

- Monthly Sales Trend
- Revenue Analysis
- Country-wise Performance
- Product Demand Analysis

---

### 🛒 Product Analysis

Identifies:

- Best Performing Products
- Low Performing Products
- Inventory Improvement Opportunities

---

### 🤖 Recommendation Engine

Automatically generates business suggestions such as:

- Inventory Optimization
- Customer Retention Strategies
- Marketing Improvements
- Sales Growth Strategies

---

### 🎛️ Interactive Filters

Dashboard includes:

- 🌍 Country Filter
- 📅 Year Filter

for dynamic analysis.

## ⚙️ How To Run

Clone the repository:

```bash
git clone <repository-url>
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open browser:

```text
http://127.0.0.1:5000
```
